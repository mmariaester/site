About the network

This network serves two purposes:
1. It is my way of having fun with graphs, which I enjoy playing around with;
2. It allows me to make a case on how I see the various aspects of my life be connected.

Each node can be seen as a topic, with varying broadness. Each edge, instead connectes two nodes if I can reasonably see myself making a direct and logical transition between them during an everyday conversation.
